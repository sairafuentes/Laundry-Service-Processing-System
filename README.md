# Laundry-Service-Processing-System

## Project Description

The Laundry Service Processing System is a Java-based desktop application designed to simplify and organize the process of managing laundry services. It helps laundry shop staff handle customer information, record laundry orders, manage service types, and monitor the queue of laundry transactions.

The system provides an organized way of processing laundry orders through a graphical user interface (GUI), reducing manual work and making laundry transactions easier to manage.

This project is developed as an academic requirement to demonstrate the application of Object-Oriented Programming (OOP) and Data Structures and Algorithms (DSA) concepts in a real-world scenario.

## Objectives

- To develop a system that organizes and manages laundry orders.
- To simplify the process of recording customer and laundry information.
- To implement a queue data structure for managing laundry orders.
- To apply object-oriented programming concepts such as inheritance, encapsulation, and polymorphism.
- To provide a user-friendly graphical interface for laundry service transactions.

## Features

- Customer Information Management – Records customer details for every laundry transaction.
- Laundry Order Management – Allows users to enter and manage laundry orders.
- Multiple Laundry Services – Supports different laundry service options, including Wash and Dry and Wash and Fold.
- Queue Management – Organizes laundry orders using the Queue data structure.
- Order Processing – Helps manage and process customer laundry transactions.
- Graphical User Interface (GUI) – Provides an easy-to-use interface for interacting with the system.

##  Concepts Applied

### Object-Oriented Programming (OOP)
- Encapsulation – Organizes data and methods within classes.
- Inheritance – Uses parent and child classes to represent different laundry services.

### Data Structures and Algorithms (DSA)
- Queue – Uses the First In, First Out (FIFO) principle to organize laundry orders.
- Enqueue – Adds new laundry orders to the queue.
- Dequeue – Removes processed orders from the queue.
- Peek/Front – Accesses the first order in the queue without removing it.

##  Project Structure

The project is organized into different Java classes, each responsible for a specific part of the system.

- `laundryGUI.java` – Handles the graphical user interface.
- `laundryQueue.java` – Manages the laundry order queue.
- `laundryOrder.java` – Represents the general laundry order.
- `washAndDry.java` – Represents the Wash and Dry service.
- `washAndFold.java` – Represents the Wash and Fold service.

Note: The project structure may vary depending on the latest implementation.

##  How to Run the Project

1. Clone or download this repository.
2. Open NetBeans IDE.
3. Select File → Open Project.
4. Locate and open the Laundry Service Processing System project.
5. Run the main GUI class.
6. Start managing laundry orders through the application.
